# Debit Order Tracker

A monthly tracker for income and debit orders: tick each line off as it goes through the account.

Live app: https://pelorus-capital-projects.github.io/Debit-Order-Tracker/

- Sign in with your username and password. Forgot the password? Your recovery code sets a new one.
- The starting figures are stored in the page locked with the recovery code. Visitors to this page only see scrambled text.
- Everything you enter is saved in the browser on your own device. Use **Backup** in the profile to keep a copy.
